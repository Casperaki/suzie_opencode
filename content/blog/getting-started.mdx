Getting started is quick and easy. In this guide, we'll walk through the essential steps to set up your account and start building.

## Step 1: Create Your Account

Sign up for a free account — no credit card required. You'll get access to all Starter plan features immediately.

## Step 2: Set Up Your First Project

Once you're in the dashboard, click **New Project** and give it a name. You can choose from several templates to get started quickly, or start from scratch.

## Step 3: Configure Your Environment

Each project has its own settings. Here are the key ones to configure:

- **API keys** — Generate keys for your development and production environments.
- **Team access** — Invite collaborators and set their permissions.
- **Integrations** — Connect your existing tools and services.

## Step 4: Deploy

When you're ready, deploy with a single click. We handle the infrastructure so you can focus on building.

```bash
# Or deploy from the command line
npx acme deploy
```

## Next Steps

Now that you're set up, explore our documentation for more advanced features:

- Custom domains
- Webhooks and event handling
- Analytics and monitoring
- CI/CD integration
